# 🧾 FacturFacile – Générateur gratuit de devis et factures

Application web **100 % gratuite à héberger**, créée pour générer des revenus
(publicité, affiliation, version PRO).

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | Page de l'application |
| `style.css` | Design (clair + mode impression A4) |
| `app.js` | Logique : lignes, totaux, TVA, sauvegarde |

## Tester sur votre ordinateur

Ouvrez simplement `index.html` dans un navigateur (double-clic).
Aucune installation, aucun serveur nécessaire.

## Mettre en ligne GRATUIMENT (GitHub Pages)

1. Créez un compte gratuit sur https://github.com
2. Cliquez **New repository** → nommez-le `facturfacile` → **Create**
3. Cliquez **uploading an existing file** et glissez les 3 fichiers → **Commit**
4. Allez dans **Settings → Pages** → Source : `main` → **Save**
5. Votre site sera visible sous : `https://VOTRE-NOM.github.io/facturfacile/`

⏱️ Total : ~15 minutes, 0 €.

Ajoutez **vos** identifiants d'affiliation dans le footer (`index.html`, recherchez `MONÉTISATION`) :
- **Hostinger** (hébergement) : programme accepté au Maroc, paie par **virement bancaire ou Payoneer** → https://www.hostinger.com/affiliates

### Étape 2 – Publicité Google AdSense (dès ~1 000 visites/mois)
AdSense **fonctionne au Maroc** : l'adresse postale marocaine est acceptée et le paiement
se fait par **chèque ou virement** (dès 100 $). Créez le compte sur https://adsense.google.com
avec ce site : `https://shekone007.github.io/facturfacile/`.

## 🌍 Vendre à l'INTERNATIONNAL depuis le Maroc

### Où encaisser les paiements internationaux (depuis le Maroc)
| Plateforme | Avantage | Payout vers le Maroc |
|---|---|---|
| **Payoneer** ✅✅ | Le standard au Maroc : reçoit USD/EUR/GBP comme un compte bancaire US/UE | Retrait guichet + carte Mastercard |
| **Paddle** ✅ | Vendeur "marchand" : gère TVA/impôts à votre place pour vous | Virement (Wire) → compte Payoneer |
| **Gumroad** ✅ | Zéro code : ils vendent la licence PRO à votre place | PayPal (limité) / virement |
| **Stripe Atlas** ⭐ | Crée une société US ($500 une fois) → vendre partout | Nécessite un compte US (Mercury) |
